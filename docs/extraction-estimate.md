# 抽出傾向の推定モデル

このスコアはレシピ変更を比べるための未校正の目安です。抽出率、TDS、味の良さを測定・予測する検証済みモデルではありません。

## 入力と計算

- 設定総湯量 = 豆量 × 湯量比。
- 工程注湯量 = 設定総湯量 × 工程の waterPercentage / 100。
- 実際の比率 = 工程注湯合計 / 豆量。工程割合が100%でなければ、その事実を表示して実際の合計で計算します。
- 工程時間はそれぞれの長さであり、累積時刻ではありません。
- 各工程で一定速度で注湯すると仮定し、注湯の中間時刻から全工程終了までの時間を注湯量で重み付けします。排水・温度低下は再現しない接触時間の代理指標です。後半の待ち時間は含み、最初の注湯より前の待ち時間は含みません。
- 湯温は各工程の指定温度（未指定なら全体温度）を注湯量で重み付けします。単なる工程数による加点は廃止しました。
- 同じ条件の工程を時間・湯量とも比例して分割しても、計算結果は変わりません。

湯量比の寄与は `12 × log2(実際の比率 / 16)`、時間の寄与は `10 × log2(加重時間 / 90秒)` とし、それぞれ−20〜+20に制限します。係数12・10、基準比率16・基準時間90秒は感度を制限する設計上の仮定で、実測から推定した係数ではありません。比率や時間の増加を常に良い味と解釈してはいけません。湯量増加は濃度低下を伴う場合があります。

## 粒径と精度の制限

S3は提供されたKenken Coffee動画スクリーンショットの中央値11点を使います。測定条件は未確認です。S3の中央値へ従来の0.55換算を重ねません。他機種は既存の仮想目盛り換算と0.55近似を維持しており、機種間の実測同等性は保証しません。微粉率、焙煎・精製・エイジングの係数も従来の仮定を引き継いでいます。

豆量と湯量を同率で拡大しても比率の寄与は変わりません。粉層の深さ、実流量、ドリッパー、浸漬／透過の違い、攪拌、自由記述の工程状態は物理モデル化していません。スコアの±18は表示区分で、過抽出／未抽出の実測判定ではありません。

入力不足、不正値、未登録機種、範囲外の挽き目にはスコアを出しません。複合目盛りは登録ラベルの完全一致を要求し、不確かな小数解釈を避けます。

## 確認

`npm test` でS3測定点、補間、比率・時間・配分・湯温の感度、工程分割の不変性、入力不足を確認します。これらは実装の整合性テストであり、実測精度の検証ではありません。次の精度評価には、測定条件の揃った粒度・TDS・抽出量・官能評価のデータが必要です。
